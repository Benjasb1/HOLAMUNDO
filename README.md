## 📌 Descripción del Proyecto
Este repositorio contiene el desarrollo de la **Actividad 2: El Taller del Programador (Hola Mundo)** de la materia Laboratorio de Programación. El objetivo principal es la configuración inicial del entorno de desarrollo integrado (VS Code), la validación del compilador GCC/MinGW (`g++`) y la implementación de un programa base en C++ con cabecera de datos personales y salida formateada por consola.
